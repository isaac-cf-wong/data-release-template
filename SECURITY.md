# Security Policy

This template is intended for small, public research data releases. Do not
commit credentials, access tokens, personal data, unpublished sensitive data, or
other secrets. Check the archive contents before publishing a release.

## Supported versions

| Version                 | Supported   |
| ----------------------- | ----------- |
| Latest template release | Yes         |
| Older releases          | Best effort |

Repositories created from this template should update this table to describe
their own release and support policy.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability reporting](https://github.com/isaac-cf-wong/data-release-template/security)
feature when it is enabled, or contact the repository maintainers privately
through the security contact listed in the project-specific README.

Include the affected file or workflow, steps to reproduce, impact, and any safe
proof of concept. Do not include secrets in the report.

We will acknowledge reports as soon as practical, investigate them, and
coordinate disclosure after a fix or mitigation is available.
